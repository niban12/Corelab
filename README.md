# CORELAB Single-File Website

Open `index.html` directly in a browser or with VS Code Live Server.

## Includes
- Responsive premium CORELAB homepage
- About, Training, Memberships, Facility, Trainers, FAQ and Contact views
- Membership enquiry modal
- Fitness Finder
- WhatsApp and call CTAs
- FAQ accordion
- Mobile navigation
- Clearly labelled temporary photography placeholders

## Demo limitation
Forms are frontend-only and do not send data to a real inbox. Membership enquiries do not process payment or activate memberships.

Before production, replace placeholders with CoreLab-approved photography and connect the forms to the real inbox/CRM/WhatsApp workflow.
