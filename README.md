# CORELAB Website

Premium functional fitness website demo for CORELAB, Banepa, Nepal — built by JARVIS Agency.

## Stack
- React
- Vite
- Tailwind CSS
- React Router
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Included
- Premium responsive homepage
- About, Training, Memberships, Facility, Trainers, FAQ and Contact pages
- Membership selection modal and enquiry form
- Fitness Finder with four steps and dynamic result
- WhatsApp message generation
- Call and Instagram CTAs
- FAQ accordion
- Temporary photography placeholders
- Mobile navigation
- Reduced-motion-friendly CSS

## Important demo limitations
- Forms are local demo interactions only. No backend or inbox delivery is connected.
- WhatsApp number `9765146040` must be confirmed by CORELAB before production.
- Replace every temporary placeholder with CORELAB-approved photography.
- Add exact address, opening hours, approved logo, trainer information, terms, privacy policy and confirmed service details before launch.
- The soft-launch offer and expiry must be reconfirmed before publishing.

## Deployment
Push this repository to GitHub, import it into Vercel, and deploy with the default Vite settings.
